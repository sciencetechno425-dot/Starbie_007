STARBiE is an Arduino-based smart plant monitoring project that helps keep track of temperature and soil moisture. It displays live readings on an LCD, checks plant conditions, provides alerts and watering recommendations, and detects when the device is tilted. It also uses EEPROM to remember tilt events and a single button to navigate through the screens. The goal is to turn simple sensor readings into useful information and make plant monitoring easier.
